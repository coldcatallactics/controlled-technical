# CTD atlas figures

| Figure | Illustrates | Source |
| --- | --- | --- |
| materials.png | Overlay and substrate roles: a light bar and popup over a dark content sheet | `source/materials.html` |
| two-layer-focus.png | Sand on the active window edge and fill-inversion focus inside surfaces | `source/two-layer-focus.html` |
| tab-strip.png | Tab joined to page: active tab in paper tone flush with the sheet, inactive tabs dark, square, shadowless, attached dropdown dark | `source/tab-strip.html` |
| typography.png | Two fixed type roles, a third content role, and tabular numerals | `source/typography.html` |
| geometry.png | Content frame grid, spacing rhythm and measured hairline geometry | `source/geometry.html` |
| surface-shape.png | Zero radius, hairline structure, the single hard offset shadow, and functional accents | `source/surface-shape.html` |
| do-and-dont.png | Five paired correct and incorrect examples with short rationales | `source/do-and-dont.html` |

Figures are 1280x800 PNGs rendered from HTML and CSS in `source/` using the
repository tokens.

Regenerate with `./examples/regenerate.sh` (needs a headless browser on PATH).

The HTML and CSS are the source of truth; the PNGs are committed outputs.
